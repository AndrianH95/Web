01

Теги тексту

Теги тексту — основа будь-якої HTML-сторінки. Вони дозволяють структурувати вміст, визначати заголовки різних рівнів, виділяти важливі слова та абзаци.

Код:
<h1>Заголовок першого рівня</h1>
<h2>Заголовок другого рівня</h2>
<h3>Заголовок третього рівня</h3>
<p>Звичайний абзац тексту.</p>
<p><strong>Жирний текст</strong> і <em>курсив</em>.</p>
<p>Перший рядок.<br>Другий рядок після br.</p>
Результат:

Заголовок першого рівня

Заголовок другого рівня

Заголовок третього рівня

Звичайний абзац тексту.

Жирний текст і курсив.

Перший рядок.
Другий рядок після тегу <br>.

02

Списки

Списки дозволяють впорядковано подавати перелік елементів. <ul> — маркований список, <ol> — нумерований.

Код:
<ul>
  <li>Елемент маркованого списку</li>
  <li>Ще один елемент</li>
</ul>

<ol>
  <li>Перший крок</li>
  <li>Другий крок</li>
</ol>
Результат:
Маркований список (ul):
  • HTML — мова розмітки
  • CSS — мова стилів
  • JavaScript — мова програмування
Нумерований список (ol):
  1. Встановити редактор
  2. Написати HTML
  3. Додати CSS
  4. Додати JS
03

Посилання та зображення

Тег <a> створює гіперпосилання. Атрибут target="_blank" відкриває посилання у новій вкладці. Тег <img> вставляє зображення, а alt описує його для доступності.

Код:
<a href="https://developer.mozilla.org" target="_blank">
  MDN Web Docs
</a>

<img src="photo.jpg" alt="Опис зображення" width="300">
Результат:

Посилання: MDN Web Docs →

Зображення з атрибутом alt="Демонстраційне зображення пейзажу"

04

Таблиці

HTML-таблиця (<table>) організовує дані в рядки (<tr>). <th> — заголовок стовпця, <td> — звичайна комірка.

Код:
<table>
  <tr>
    <th>Технологія</th>
    <th>Призначення</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>Структура</td>
  </tr>
</table>
Результат:
Технологія Призначення Розширення файлу
HTML Структура сторінки .html
CSS Стилізація елементів .css
JavaScript Інтерактивність .js
05

Форми

Тег <form> збирає дані від користувача. <label> підписує поле, <input> приймає введення, <button> — кнопка дії.

Код:
<form>
  <label for="name">Ім'я:</label>
  <input type="text" id="name" placeholder="Введіть ім'я">

  <label for="email">Email:</label>
  <input type="email" id="email" placeholder="example@mail.com">

  <button type="submit">Надіслати</button>
</form>

06

Box Model

Кожен HTML-елемент — це прямокутна коробка. Box Model описує її з 4 шарів: content → padding → border → margin.

Код CSS:
.box {
  width: 200px;
  padding: 20px;
  border: 3px solid #e63;
  margin: 30px;
}

07

Typography

CSS-властивості шрифтів визначають читабельність тексту. font-size — розмір, font-weight — жирність, line-height — міжрядковий інтервал.

Код CSS:
.typo-small  { font-size: 12px; font-weight: 400; line-height: 1.2; }
.typo-medium { font-size: 18px; font-weight: 500; line-height: 1.5; }
.typo-large  { font-size: 28px; font-weight: 700; line-height: 1.8; }
Результат:

font-size: 12px · font-weight: 400 · line-height: 1.2 — дрібний текст підписів

font-size: 18px · font-weight: 500 · line-height: 1.5 — основний текст

font-size: 28px · font-weight: 700 · line-height: 1.8 — великий заголовок

Layout — Flexbox

display: flex активує Flexbox. gap — відступ між елементами, justify-content — вирівнювання по головній осі, align-items — по поперечній.

.flex-container {
  display: flex;
  gap: 16px;

  align-items: center;

Псевдокласи та hover-ефект

Псевдокласи стилізують елементи залежно від стану. :hover — при наведенні миші, :focus — при активації клавіатурою або кліком.

Код CSS:
.hover-btn:hover {
  background-color: #6c63ff;
  transform: translateY(-3px);
  box-shadow: 0 8px 24px rgba(108,99,255,0.4);
}

.focus-input:focus {
  outline: 2px solid #6c63ff;
  border-color: #6c63ff;
}

Додавання контенту (DOM)

JavaScript змінює HTML-сторінку через DOM (Document Object Model). document.createElement() створює новий елемент, appendChild() додає його в дерево сторінки.

Код JS:
document.getElementById("addBtn").addEventListener("click", function() {
  const p = document.createElement("p");
  p.textContent = "Новий абзац #" + (++count);
  p.className = "added-item";
  document.getElementById("output").appendChild(p);
});

12

Події та зміна стилю

Подія (event) — сигнал про дію користувача. addEventListener підписує функцію на подію. JS змінює стилі через element.classList.toggle().

Код JS:
document.getElementById("themeBtn").addEventListener("click", function() {
  document.body.classList.toggle("dark-theme");
  this.textContent = document.body.classList.contains("dark-theme")
    ? "☀️ Світла тема"
    : "🌙 Темна тема";
});
Результат:

🎉 Це приховане пояснення! Ти показав його за допомогою JavaScript.

Метод classList.toggle() додає клас, якщо його немає, і видаляє, якщо він є.
